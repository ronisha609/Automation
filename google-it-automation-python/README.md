# Python IT Automation | Learning Reference Collection

A course-based reference collection covering Python scripting, operating-system tasks, troubleshooting, reporting, and automation. The original README credits **Kyungrae Kim**, and that attribution is retained below. This collection should be presented as a learning reference rather than code independently authored by Ronisha Showers.

## Skills & Learning Outcomes

This reference material supports learning how to break administration tasks into functions, read and summarize records, inspect system conditions, and troubleshoot scripts. It helps connect Python fundamentals to repeatable IT tasks. These are study opportunities provided by the examples, not claims of independently authored solutions.

## Useful Examples to Explore

| Example | What the code does | Skill area |
| --- | --- | --- |
| [System health checks](using-python-to-interact-with-the-operating-system/week-one/health_checks.py) | Checks available disk space and CPU usage, then evaluates network checks. | System monitoring and conditional logic |
| [CSV department reporting](using-python-to-interact-with-the-operating-system/week-two/generate_report.py) | Reads employee records, counts employees by department, and writes a sorted report. | CSV parsing, data aggregation, and report generation |
| [File and text processing](using-python-to-interact-with-the-operating-system/week-five) | Includes text-processing examples and tests. | Python scripting and unit testing |
| [Troubleshooting exercises](troubleshooting-and-debugging-technique) | Organizes debugging and performance-related learning material. | Troubleshooting foundations |

The first two descriptions were checked against the source files. They are code capabilities, not claims of a newly completed execution or original authorship. Some scripts contain course-specific paths and need adaptation before running locally.

## Original Course README & Attribution

### Google IT Automation With Python

Author: Kyungrae Kim  
Status: Completed

This repository is created to keep track of [Google IT Automation With Python](https://www.coursera.org/professional-certificates/google-it-automation) provided by Coursera. This program is developed by Google and designed to teach how to program with Python and how to use Python to automate common system administration tasks. Also, the course will teach how to use Git and GitHub, troubleshoot and debug complex problems, and apply automation at scale by using configuration management and the Cloud.
